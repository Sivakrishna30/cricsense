These archives are local research inputs only.

Do not expose raw contents in production code or public APIs.

## Files

- `cricsheet_all_json.zip`
  - primary structured historical cricket backbone
- `commentary_full_ipl_2017_2025.zip`
  - full IPL commentary rows
- `commentary_text_ipl_2023_txt.zip`
  - per-match IPL 2023 text commentary files
- `commentary_highlights_ipl_2008_2020_a.zip`
  - IPL highlight commentary snippets
- `commentary_highlights_ipl_2008_2020_b.zip`
  - duplicate/additional IPL highlight commentary snippets
- `structured_ipl_sql_dump.zip`
  - SQL dump with extra IPL structured fields
- `structured_ipl_ball_by_ball_2024.zip`
  - structured IPL ball-by-ball data
- `enriched_ball_by_ball_multiformat.zip`
  - enriched multi-format ball-by-ball data with shot/length/style fields
- `misc_asia_champions_trophy.zip`
  - unrelated tournament summary dataset
- `notebook_ipl_analysis.zip`
  - notebook/archive reference only
